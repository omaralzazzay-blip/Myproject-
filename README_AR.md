# نظام إدارة المشاريع الإنشائية المتكامل — النسخة الموسّعة

نظام معلوماتي متكامل لإدارة المشاريع الإنشائية: الإدارة المالية، الموارد البشرية (العمال)، المخزون مع **قسم التالف**، **المصروفات والمسحوبات** على مستوى العامل/المشرف/المادة، **قائمة الحسابات (مدين/دائن)**، **المرفقات** (فواتير ومخططات)، والتقارير المتقدمة مع تصدير **PDF و Excel** — بواجهتين: **لوحة تحكم المدير** و**لوحة المشرف**، مع دعم تعدد العملات وفارق الصرف وإشعارات وحماية بالدخول.

---

## 1) المتطلبات
- **XAMPP** (Apache + MySQL/MariaDB + phpMyAdmin): https://www.apachefriends.org
- **Python 3.9+**
- مكتبات بايثون (تُثبَّت خطوة 3):
  - `flask`, `pymysql`, `werkzeug`
  - `reportlab` + `openpyxl` (تصدير PDF و Excel)
  - `arabic-reshaper` + `python-bidi` (عرض العربية في ملفات PDF)

---

## 2) تجهيز قاعدة البيانات (MySQL)
1. شغّل XAMPP ثم ابدأ خدمتي **Apache** و **MySQL**.
2. افتح phpMyAdmin: http://localhost/phpmyadmin
3. التبويب **استيراد (Import)** ← اختر **`database/schema.sql`** ← تنفيذ.
   - يُنشئ قاعدة البيانات `construction_management` بـ **29 جدولاً** مع بيانات تجريبية كاملة.
4. لتغيير بيانات الاتصال: عدّل `config.py` (`DB_USER`, `DB_PASSWORD`, `DB_NAME`).

---

pip install -r requirements.txt

## 4) المزايا الجديدة المضافة لهذه النسخة

### 4.1 إدارة الأصناف التالفة لكل مخزن
- كل مخزن فيه **قسم تالف مستقل** يُعرض داخل صفحة المخزن وعلى نظرة المخازن العامة.
- يُربط التالف بالمخزن + المادة + النوع الفرعي + وحدة القياس + السبب + التاريخ + القيمة.
- حركة «تالف» تُسجَّل تلقائياً في قسم التالف وتحتسب من الرصيد (مع منع الرصيد السالب).

### 4.2 المصروفات والمسحوبات (عامل / مشرف / مادة)
- قسم جديد **«المصروفات والمسحوبات (صرف)»** في القائمة الجانبية.
- كل قيد يرتبط بـ: المادة (الصنف) + العامل المستفيد أو المشرف المسؤول + المشروع + المخزن.
- يدعم **صرف مواد** من المخزن (مع حركة مخزنية مرتبطة) و**مبالغ نقدية / سلف**.
- **تُخصم قيمة القيد تلقائياً من حساب العامل أو المشرف** في قائمة الحسابات.

### 4.3 نظام تقارير متقدم (مع تصدير PDF و Excel بالعربية)
- **كشف حساب عامل** — كل مسحوباته وصرفياته مع الإجمالي.
- **كشف حساب مشرف** — كل ما صُرِف على حسابه.
- **حركة مادة** — حركة كاملة (إدخال/صرف/إرجاع/تالف) مع رصيد جارٍ، ونوع فرعي، ومخزن، حسب الفترة.
- **تقرير التالف** — كميات وقيم التالف حسب المخزن والمادة والسبب.
- **التقرير العام (يومي/أسبوعي/شهري/سنوي)** و**التقرير المالي الشامل** — مع أزرار تصدير PDF و Excel لكل تقرير، والمخرجات العربية مضبوطة الاتجاه (RTL).

### 4.4 تعدد وحدات القياس والأنواع لكل مادة
- عند إضافة مادة: تُحدَّد **وحدة أساسية** + **وحدات إضافية** (قطعة، متر، كيلو، لتر...).
- تُحدَّد **أنواع فرعية متعددة** (مثال: خشب كرد، خشب ألواح، خشب مرابيع) — إضافة/حذف ديناميكي.
- كل نوع وكل وحدة **مرتبطان بقسم التالف الخاص بهما** في كل مخزن.

### 4.5 قائمة الحسابات (مدين / دائن)
- قسم جديد **«قائمة الحسابات (مدين/دائن)»** (للمدير).
- **مدين**: يُعترف به عند تحصيله فعلياً — أساس الاستحقاق النقدي للمدين (زر تحصيل يُدخل المبلغ للميزانية عبر الحساب الرئيسي).
- **دائن**: يُخصم **مباشرة من ميزانية المشروع** عبر الحساب الرئيسي فور تسجيله.
- حساب رئيسي تلقائي لكل مشروع + حسابات تلقائية للعمال والمشرفين عند أول صرف.
- كل حساب بكشف قيوده (مدين/دائن) ورصيده بالعملة المحلية.

### 4.6 إرفاق المستندات والفواتير والمخططات
- قسم **«الفواتير والمستندات والمخططات»** لرفع: JPG, PNG, PDF, DWG, DOC, XLS...
- يُرفق فاتورة التوريد مباشرة من شاشة المورد (ترفع تلقائياً مع التوريد).
- كل مرفق مرتبط بمشروع وبنوع العملية (توريد/مصروف/صرف/عام...).

### 4.7 إدارة المرتجعات والتالف
- حركة **«إرجاع للمخزن»** تزيد الرصيد تلقائياً.
- حركة **«تالف»** تُنقل لقسم التالف وتنقص الرصيد تلقائياً.
- جميع الحركات تتحقق من الرصيد وتُحدّثه فوراً (تمنع السالب).

---

## 5) ملاحظة محاسبية مهمة (تباين أساس المعالجة)
- **المدين** يُعترف به **عند التحصيل الفعلي فقط** (الأساس النقدي للمدين) — فلا يظهر في موارد المشروع إلا بعد زر «التحصيل».
- **الدائن** يُخصم **فوراً** من ميزانية المشروع عند تسجيله.
- هذا التباين المقصود موثّق في النظام نفسه (شاشة الحسابات والتقرير المالي) لضمان وضوح أثر كل قيد.

## 6) هيكل قاعدة البيانات (الملخص)
| الجدول | الوصف |
|---|---|
| `warehouses` | المخازن (اسم، موقع، مسؤول) |
| `materials` | المواد الأساسية (اسم، وحدة أساسية، سعر) |
| `material_types` | الأنواع الفرعية للمادة (مثال: خشب كرد) |
| `material_units` | وحدات القياس المتاحة لكل مادة (متعدد) |
| `stock_movements` | إدخال/صرف/إرجاع/تالف |
| `damaged_goods` | قسم التالف لكل مخزن/مادة/نوع مع السبب والتاريخ |
| `workers` | بيانات العمال |
| `issues` | المصروفات والمسحوبات (عامل/مشرف/مادة/مشروع) |
| `accounts` | قائمة الحسابات (مدين/دائن/عامل/مشرف/رئيسي) |
| `account_entries` | قيود الحسابات (دائن/مدين) |
| `attachments` | الفواتير والمخططات والمستندات |
| `projects` | المشاريع وربط الحسابات بها |

(إضافةً للجداول الأصلية: العملات، الميزانيات، الممولون، الموردون، المصاريف، المسحوبات، الإشعارات...)

---

## 7) استكشاف الأخطاء
- **فاتورة تصدير PDF فارغة/خطأ خطوط**: تأكد من وجود مجلد `assets/fonts` بجانب `exporters.py` (مرفق بالحزمة).
- **تغيير منفذ**: عدّل `run.py` أو شغّل `python run.py` بعد تعديل `app.run(...)`.
- **أذونات الرفع**: تأكد من قابلية الكتابة لمجلد `uploads` (يُنشأ تلقائياً أول تشغيل).
